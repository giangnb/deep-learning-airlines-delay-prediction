## Problem Statement
The project introduces prediction Deep Learning model that trained against millions of flight records to give prediction of dailed reason of delay based on flight details.

Key considered features:
- Flight time (day, month, day of week)
- Origin and Destination airports
- Scheduled depature
- Flight distance

Prediction output, delay reasons:
- Weather conditions
- Carrier operations
- Airport/Navigation operations
- Security issues
- Late aircraft arrival

## Approaches
- Data collection and acquisition pipeline
- Data pre-processing
- Features engineering
- Artificial Neural Network model training
    - Time series approaches
    - Recurring Neural Network with GRU
    - Transformers

## Dataset
- Data colelcted from the Department of transportation, USA
- Scope: All domestic US flights between 2023 and 2025
